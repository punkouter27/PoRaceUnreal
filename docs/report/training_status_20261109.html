TensorBoard logs dozens of numbers; these three tell the story. Each point is a test of 128 fresh episodes, taken every 10.6 million practice steps. The dashed line marks where the run started, which is m20's own score on the new, harder task.

What it means: the run lasted 202 million steps; the score only climbed in the last 20 minutes (62.5 at the end), and the ladder test confirmed no real gain. When things finish

Estimated from this PC's measured speed: about 45,000 practice steps per second, so roughly one hour per 150-million-step run. The GPU runs one training job at a time; tests run on the CPU alongside it.

Grandma's run 1 failed in the known way Matt's early runs did (m2–m4): when standing earns less than falling, the policy falls. Once the scoring is fixed, 3–5 runs is still a fair guess: roughly 5–7 GPU hours, so racing tomorrow evening at the earliest.
